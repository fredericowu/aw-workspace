# aw-workspace-cli marketplace --help

**Como eu instalo ou atualizo um app pelo marketplace?** / **How do I install or update an app from the marketplace?**

Install or update apps from the marketplace catalog

`aw-workspace-cli marketplace`

```
usage: aw-workspace-cli marketplace [-h] {install,update-all,info} ...

Install or update apps from the marketplace catalog

positional arguments:
  {install,update-all,info}
    install             Install (or update) an app from the catalog
    update-all          Update every installed app to the catalog's current
                        version
    info                List installed apps and their versions

options:
  -h, --help            show this help message and exit
```

# aw-workspace-cli marketplace install --help

**Como eu uso o comando `aw-workspace-cli marketplace install`?** / **How do I use `aw-workspace-cli marketplace install`?**

Install (or update) an app from the catalog

`aw-workspace-cli marketplace install`

```
usage: aw-workspace-cli marketplace install [-h] [--update] app

positional arguments:
  app         App id/slug as listed in the marketplace catalog

options:
  -h, --help  show this help message and exit
  --update    Update an already-installed app to the catalog's current version
```

# aw-workspace-cli stop --help

**Como eu paro um componente da workspace?** / **How do I stop a workspace component?**

Stop a workspace component (app container or managed service)

`aw-workspace-cli stop`

```
usage: aw-workspace-cli stop [-h] component

Stop a workspace component (app container or managed service)

positional arguments:
  component   App slug or component key

options:
  -h, --help  show this help message and exit
```

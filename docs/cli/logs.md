# aw-workspace-cli logs --help

**Como eu vejo os logs de um componente da workspace?** / **How do I see a workspace component's logs?**

Show (or follow) a component's logs

`aw-workspace-cli logs`

```
usage: aw-workspace-cli logs [-h] [-f] component

Show (or follow) a component's logs

positional arguments:
  component     App slug or component key

options:
  -h, --help    show this help message and exit
  -f, --follow  Keep streaming until interrupted
```

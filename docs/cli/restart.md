# aw-workspace-cli restart --help

**Como eu restarto a aw-workspace rodando?** / **How do I restart a running workspace?**

Restart a workspace component (app container or managed service), or the core process itself

`aw-workspace-cli restart`

```
usage: aw-workspace-cli restart [-h] component

Restart a workspace component (app container or managed service), or the core
process itself

positional arguments:
  component   App slug or component key

options:
  -h, --help  show this help message and exit
```

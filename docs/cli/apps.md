# aw-workspace-cli apps --help

**Como eu listo os apps instalados de uma workspace?** / **How do I list the apps installed on a workspace?**

List installed apps (add --json for the raw payload)

`aw-workspace-cli apps`

```
usage: aw-workspace-cli apps [-h] [--json] [slug]

List installed apps (add --json for the raw payload)

positional arguments:
  slug        Show one app's full record

options:
  -h, --help  show this help message and exit
  --json      Print the raw JSON instead of a table
```

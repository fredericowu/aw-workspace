# aw-workspace-cli folders browse --help

**Como eu uso o comando `aw-workspace-cli folders browse`?** / **How do I use `aw-workspace-cli folders browse`?**

List subdirectories, to find a path to map

`aw-workspace-cli folders browse`

```
usage: aw-workspace-cli folders browse [-h] [path]

positional arguments:
  path        Directory to list (default: workspace root)

options:
  -h, --help  show this help message and exit
```

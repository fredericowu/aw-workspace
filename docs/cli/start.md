# aw-workspace-cli start --help

**Como eu inicio um componente da workspace?** / **How do I start a workspace component?**

Start a workspace component (app container or managed service)

`aw-workspace-cli start`

```
usage: aw-workspace-cli start [-h] component

Start a workspace component (app container or managed service)

positional arguments:
  component   App slug or component key

options:
  -h, --help  show this help message and exit
```
